# osdev-jp-tester
Test [osdev.jp](https://github.com/osdev-jp/osdev-jp.github.io) locally

```
/somewhere $ git clone https://github.com/TaiseiIto/osdev-jp-tester.git
/somewhere $ cd osdev-jp-tester
/somewhere/osdev-jp-tester $ ./run.sh -r https://github.com/osdev-jp/osdev-jp.github.io -b master
```
